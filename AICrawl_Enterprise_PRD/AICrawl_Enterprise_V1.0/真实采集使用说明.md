# 真实内容与工具接入

本轮新增 PyPI 官方公开 JSON API 连接器，用于研发组件版本与依赖元数据监测。固定支持 FastAPI、Scrapy、Playwright 三个项目，不安装、下载或执行软件包。字段包含版本、摘要、Python 版本要求、依赖、许可证表达式和发布时间；缺失字段保持空值。元数据由项目上传者提供，不代表经过安全审计。

## 使用步骤

1. 启动 `python run.py`，打开控制台。
2. 数据源中心找到 PyPI 来源，点击审批启用，填写内部使用目的与准入依据。
3. 创建任务并选择启用的 PyPI 来源，手动执行。
4. 数据资产中查看版本、依赖和原始 info 字段证据，或导出 CSV。
5. 工具中心可查看真实能力。环境中已安装某个包不等于系统已集成该引擎。

## 行为边界

- 样本与 PUBLIC_API 来源明确区分，真实接口失败批次显示 FAILED，不生成替代样本。
- 固定 HTTPS 官方地址，禁止重定向、禁用环境代理、验证 TLS、8 秒网络超时、2MB 响应限制；全进程请求启动间隔至少 1 秒；不自动重试错误响应。
- 不提供任意目标 URL 输入，也不处理登录网站、验证码或企业私有 API。
- 原始 info 字段保留在内存记录中，响应 SHA-256 针对完整接收字节计算；完整响应字节暂未归档，不能用于重启后的证据回放。
- 审批为本地操作记录，不代替企业法务审查。企业内部接口、SSO、模型和代理需要实际账号配置；当前均未连接。
- 不填写虚构企业客户、订单、营收、授权或生产 SLA。统计来自本进程实际任务。
- 沿用无数据库模式，重启会丢失任务与记录；当前不适合公开网络部署。

接口依据：https://docs.pypi.org/api/json/
