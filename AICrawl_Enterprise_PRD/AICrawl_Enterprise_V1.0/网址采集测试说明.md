# 网址采集测试

左侧进入“网址采集测试”，点击“输入网址开始测试”。填写 HTTPS 地址、实际用途和访问依据，勾选访问权限确认后提交。系统自动建立网页来源、记录本机审批、建立任务与批次；结果在运行批次和数据资产查看。

预置百度、淘宝、Python 官网的浏览器链接及填入按钮。填入不立即请求。百度的通用爬虫 robots 禁止规则可能导致 BLOCKED；淘宝可能出现规则禁止、登录、验证码或动态骨架，这些都不代表已成功采集商品。

当前支持单页标题、可见文本与最多 100 个链接，不下载链接目标、不执行 JavaScript、不提取通用商品价格。可见文本最多 20000 字符，原文证据截取最多 50000 字符，响应最多 1MB。完整响应 SHA-256 与截取标志保存在证据中。没有标题时使用主机名，空正文进入质量复核。

网络规则：仅 HTTPS 443；禁止凭据、内网、本机和保留 IP；DNS 结果全部校验，建立连接时固定已验证 IP，TLS 仍验证原主机名；不使用环境代理、Cookie 或伪造搜索引擎身份。每次先请求 robots.txt；404/410 作为没有规则文件处理，其他非成功响应拒绝目标请求；明确禁止停止。超过 1 秒的 crawl-delay 暂不支持并停止。所有网页请求串行且间隔至少 1 秒。目标跳转、401/403/429 或验证码均停止，不自动重试。

任意域名 DNS 查询依赖操作系统解析器；网络请求使用 8 秒 socket 超时。当前是本机测试能力，不能替代生产环境的网络出口隔离和 DNS 超时治理。

源码入口：backend/web_fetch.py；接口：POST /api/v1/web-tests，JSON 字段 url、note、authorized=true。输入框只能提交公开、获准访问的页面；权限勾选属于用户声明，不代表企业法律审批。

继续保持无数据库模式，重启清空记录。真实请求失败不会生成样本结果。当前说明优先于早期“无法输入任意地址”的历史说明。
